# Changelog

## 0.1.0

- Registries view: search and install items from ogimagecn, shadercn, pdfcn, termcn and shadcn-cssinjs.
- **Add Registry Item…** quick pick across all Shadcn Labs registries.
- Localhost bridge for the Shadcn Labs browser toolbar: install items and open Open Graph image sources in the editor.
- **Set Up Browser Toolbar** command running `@shadcn-labs/devtools init`.
- Status bar indicator and **Show Toolbar Bridge Status**.
